# Security policy

Please do not report suspected security vulnerabilities in public issues.

Use GitHub private vulnerability reporting for this repository:

https://github.com/bkrabach/amplifier-smart-tool-music-deck/security/advisories/new

Provide a minimal reproduction and impact description, and avoid including credentials, tokens, client IDs, account data, device details, or raw live output. Reports are handled on a best-effort basis; this project makes no response-time commitment.

This security route is for vulnerabilities only. For non-sensitive project questions or bugs, use https://github.com/bkrabach/amplifier-smart-tool-music-deck/issues. Do not use the vulnerability form for conduct concerns.
