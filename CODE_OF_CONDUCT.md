# Code of Conduct

Participate respectfully. Harassment, discriminatory behavior, threats, and disclosure of another person's private information are not acceptable in this repository.

Maintainers may moderate repository participation, including issues, pull requests, and discussions in project spaces, to keep collaboration constructive and safe.

For a non-sensitive moderation concern, open an issue without including private details: https://github.com/bkrabach/amplifier-smart-tool-music-deck/issues

For platform abuse, use GitHub's reporting tools. GitHub handles those reports; using them does not imply that project maintainers receive a private report. Do not use the security vulnerability form for conduct reports.
