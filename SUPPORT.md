# Support

This community project offers best-effort support through GitHub Issues:

https://github.com/bkrabach/amplifier-smart-tool-music-deck/issues

Before filing, check the README, the usage guide, and the Spotify app setup guide. Use the issue templates where they fit, and sanitize logs and examples: do not post tokens, client IDs, account data, device details, private playlist information, or raw output from live runs.

GitHub Discussions is not enabled for this repository. There is no dedicated support email or response-time commitment. Security vulnerabilities belong in the private reporting route described in [SECURITY.md](SECURITY.md).
